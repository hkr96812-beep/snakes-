# Desert Knight — Mobile WebGL Edition

هذه نسخة ويب مستقلة من لعبة Desert Knight تعمل مباشرة من المتصفح على الهاتف والكمبيوتر.

> ملاحظة: هذه النسخة تستخدم WebGL مباشرة داخل المتصفح، وليست Unity WebGL Build؛ لذلك لا تحتاج إلى تثبيت Unity أو Unity Editor لتشغيلها.

## التشغيل محليًا
افتح `index.html` في متصفح حديث يدعم WebGL. إذا منع المتصفح التشغيل من `file://` استخدم أي خادم ملفات محلي بسيط.

## رفعها إلى GitHub Pages
1. أنشئ Repository جديدًا في GitHub.
2. ارفع `index.html` و`style.css` و`game.js` إلى الفرع الرئيسي.
3. من Settings → Pages اختر Deploy from a branch.
4. اختر `main` و`/root` ثم Save.
5. بعد اكتمال النشر سيظهر لك رابط الموقع، ويمكن فتحه من الهاتف.

## التحكم
- الهاتف: أزرار الأسهم أسفل الشاشة.
- الكمبيوتر: WASD أو الأسهم.
- اضغط على المدينة عند الاقتراب منها لفتح لوحة المدينة.
- في المعركة اضغط «عودة للخريطة» لحسم المعركة.
- الحفظ والتحميل يستخدمان LocalStorage في المتصفح.
